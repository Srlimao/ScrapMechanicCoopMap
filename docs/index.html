FAQ & SECURITY

Frequently Asked Questions

How does the Radar Proxy DLL (dinput8.dll) work? Is it safe?

100% Safe. The bundled dinput8.dll is a standard proxy wrapper that sits alongside ScrapMechanic.exe in your game folder. It simply executes a lightweight telemetry probe in the game's official Lua environment every 500ms to report entity coordinates. It does not modify game files, does not touch original executable code, and Scrap Mechanic has no VAC bans.

What if the app cannot find my Scrap Mechanic install path?

If your game is installed on a secondary SSD or custom drive, open Settings (⚙️) in the top header and click Browse... to select your Scrap Mechanic/Release folder directly.

Why does Windows SmartScreen show an "Unknown Publisher" prompt?

Windows displays this blue warning on freshly compiled open-source binaries that do not have an expensive $400/yr corporate EV certificate. You can safely click "More info" → "Run anyway". All source code is completely open for inspection on GitHub.

Do my friends need to be on the same local network / WiFi?

No! Squad room codes synchronize over our high-speed cloud relay server (WSS). Anyone in your squad anywhere in the world can enter your room code and see live positions.

Where can I find my Scrap Mechanic save file (.db)?

Your survival worlds are saved in your Windows AppData directory:
%AppData%\Roaming\Axolot Games\Scrap Mechanic\User\User_<SteamID>\Save\Survival\
